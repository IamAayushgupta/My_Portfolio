# 🌟 Aayush Gupta – Flutter Portfolio Website

A modern, fully responsive portfolio built using Flutter Web. The portfolio showcases my projects, skills, experience, and provides a seamless way for clients or recruiters to connect with me.

## 🚀 Features

- Fully responsive UI (Mobile, Tablet & Desktop)
- Smooth scroll navigation between sections
- Project showcase with images, tags, GitHub links & live demos
- Contact form with mail integration
- Resume download feature
- Hover animations & rich UI interactions
- Clean, reusable widget structure
- Asset-based project thumbnails
- Firebase, REST APIs and AI expertise highlighted

---

## 🛠️ Tech Stack

- **Flutter (Web)**
- **Dart**
- **Provider / Local State**
- **Firebase**
- **Git & GitHub**
- **REST APIs**
- **Universal HTML (for resume download on web)**
